# Larchsend (demo site)

A fictional email marketing brand used by [Knownwise](https://knownwise.com) to demonstrate its AI-visibility audit and fixer. Larchsend is not a real company. The site has deliberate, realistic issues (robots rules that block AI crawlers on the blog, missing structured data, long titles, missing meta descriptions, missing alt text, duplicate H1s) so the fixer has something real to fix.

Built with Astro. `npm install && npm run build`.
